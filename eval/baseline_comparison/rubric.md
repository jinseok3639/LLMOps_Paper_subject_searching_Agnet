# 평가 루브릭

심판(GPT)과 사람 검증자가 같은 기준을 씁니다. 심판 프롬프트(`prompts/judge_score.md`, `prompts/judge_novelty.md`, `prompts/judge_pairwise.md`)는 이 문서의 영어판입니다. 기준을 고치면 네 파일을 함께 고칩니다.

## 심판에게 주는 정보

| 준다 | 주지 않는다 |
|---|---|
| 참고문헌 세트 (`corpus_text()`와 같은 형식) | 어느 조건(A, B, C)의 후보인지 |
| 생성 태스크 설명 (A·C 공통 프롬프트의 태스크 부분) | 모델 이름, 워크플로우 구조 |
| 후보 (필드를 고정 순서의 JSON으로 정규화) | 원 논문(정답 논문) |
| 이 루브릭 | 다른 조건의 점수 |

- 주 항목 1~5는 **주어진 참고문헌만으로** 판단합니다. 외부 지식이나 검색을 쓰지 않습니다.
- 항목 6(외부 새로움)만 학술 DB 검색을 허용합니다. 검색어와 찾은 논문을 출력에 남기고, 주 점수와 합치지 않고 따로 보고합니다.
- 형식 규칙(summary 단어 수, 결과 보고, 없는 id)은 생성 단계에서 `problems()`로 이미 걸렀으므로 채점하지 않습니다.

## 후보별 점수 (1~5점)

1, 3, 5점에 기준을 둡니다. 2점과 4점은 그 사이입니다.

### 1. 근거 (grounding)
선행 연구에 대한 주장이 주어진 참고문헌으로 뒷받침되는가. `support`의 논문이 실제로 관련 있는가.

| 점수 | 기준 |
|---|---|
| 1 | 참고문헌에 없는 내용을 선행 연구의 사실처럼 말하거나, `support`의 논문 대부분이 아이디어와 관련 없음 |
| 3 | 핵심 주장은 뒷받침되지만, 일부 주장이 과장되었거나 `support`에 관련 없는 논문이 섞임 |
| 5 | 선행 연구에 대한 모든 주장이 참고문헌으로 확인되고, `support`가 아이디어의 근거를 정확히 가리킴 |

### 2. gap의 타당성
제시한 gap이 참고문헌에서 실제로 남아 있는 문제인가.

| 점수 | 기준 |
|---|---|
| 1 | 참고문헌이 이미 해결한 문제를 gap이라 하거나, gap이 막연함 ("더 연구가 필요하다") |
| 3 | gap은 실재하지만 참고문헌에서 자연스럽게 이어지지 않거나 범위가 넓음 |
| 5 | 참고문헌의 구체적인 한계에서 나온, 범위가 분명한 gap |

### 3. 구체성과 검증 가능성
approach와 evaluation만 보고 실험 설계를 시작할 수 있는가.

| 점수 | 기준 |
|---|---|
| 1 | 방법이 일반론이고 ("새 프레임워크를 제안한다") 비교 대상이나 측정 지표가 없음 |
| 3 | 방법의 핵심은 있지만, 비교 대상이나 측정 지표 중 하나가 모호함 |
| 5 | 대상, 바꾸는 것, 기법, 비교 대상, 측정 지표가 모두 구체적임 |

### 4. 일관성
gap, approach, evaluation이 서로 맞물리는가.

| 점수 | 기준 |
|---|---|
| 1 | approach가 gap을 다루지 않거나, evaluation이 approach의 효과를 측정하지 못함 |
| 3 | 대체로 이어지지만 한 고리가 약함 |
| 5 | gap을 approach가 직접 다루고, evaluation이 그 주장을 확인하거나 반박할 수 있음 |

### 5. 연구 가치
연구자가 이 후보를 골라 실제로 진행할 만한가. 새로움 자체가 아니라, 결과가 분야의 판단을 바꿀 수 있는지를 봅니다.

| 점수 | 기준 |
|---|---|
| 1 | 결과가 어느 쪽으로 나와도 알게 되는 것이 거의 없음, 또는 기존 연구의 단순 조합 |
| 3 | 의미는 있지만 영향 범위가 좁음 |
| 5 | 결과가 해당 연구 흐름의 가정이나 방법 선택을 바꿀 수 있음 |

### 6. 외부 새로움 (따로 보고)
학술 DB 검색으로 이미 같은 연구가 있는지 확인합니다. 참고문헌에 이미 같은 연구가 있으면 항목 2에서 감점하고, 여기서는 참고문헌 밖의 문헌만 봅니다.

| 점수 | 기준 |
|---|---|
| 1 | 핵심 아이디어를 그대로 수행한 논문이 있음 |
| 3 | 매우 가까운 연구가 있지만 대상이나 방법 중 하나가 다름 |
| 5 | 검색으로 가까운 연구를 찾지 못함 |

## 세트 단위 쌍대 비교

후보 3개 세트 두 개(X, Y)를 한 번에 보여주고, 항목마다 X, Y, 무승부 중 하나를 고릅니다. 같은 쌍을 X/Y, Y/X 순서로 두 번 평가하고, 두 결과가 다르면 무승부로 처리합니다.

| 항목 | 질문 |
|---|---|
| 최고 후보 | 각 세트에서 가장 좋은 후보끼리 비교하면 어느 쪽이 나은가 |
| 최저 후보 | 각 세트에서 가장 약한 후보끼리 비교하면 어느 쪽이 나은가 |
| 다양성 | 세 후보가 서로 다른 gap이나 접근을 다루는가 (같은 아이디어의 변형이면 낮음) |
| 종합 | 연구자에게 후보 3개를 보여준다면 어느 세트가 나은가 |

판단 기준은 항목 1~5와 같고, 외부 새로움은 쓰지 않습니다.

## 출력 규칙

- 항목마다 근거를 먼저 쓰고 점수나 판정은 마지막에 씁니다.
- 근거에는 참고문헌 id를 인용합니다.
- JSON으로만 답합니다.

## 사람 검증

후보별 점수에서 무작위로 일부를 골라 사람이 같은 루브릭으로 채점하고, 심판과의 일치도를 봅니다. 시범 운영(t003~t005, 후보 27개)에서는 9개 정도를 봅니다.
